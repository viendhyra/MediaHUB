# Выпуск 22.0: план и статус

## Выполнено

1. Изучены серверная версия 21.51, прежний установщик, журнал изменений и Android 0.6.0.
2. Собран отдельный репозиторий: только исходники, рабочие инструменты, документация, тесты и подписанный APK. ZIP прошлых версий, временные скрипты, кэши, личные SSH-настройки и ключи не входят.
3. Подготовлен установщик отдельной Debian 13 VM в Proxmox: выбор VM ID, хранилищ, CPU/RAM, дисков, DHCP/статического IP, проверка SHA-512 cloud-образа, cloud-init, гостевой агент и ключ администратора.
4. Новая VM получает отдельный диск медиатеки и автоматически связанный комплект qBittorrent/Prowlarr/Radarr/Sonarr. Jellyfin не устанавливается и не предлагается в обычных настройках.
5. Добавлены настройки приложений, локальное скачивание APK с версией и SHA-256, инструкции Android TV, телефона, планшета и альтернативных платформ.
6. Добавлены проверка GitHub и новости коммита, установка обновлений через systemd, команды обновления и перехода со старого сервера, резервное копирование и откат кода/базы при ошибке запуска.
7. Подготовлены README, скриншоты, обложка, BAT установки/обновления/публикации и GitHub Actions.

## Проверка

- Успешно прошли 47 unittest и GitHub Actions на Linux/Windows (run 37155914678), включая ShellCheck.
- Существующие проверки плеера, импорта страниц, картинок и релизов.
- Новые проверки версии, привязки новостей к коммиту, кэша, отсутствия интернета, доступа из LAN и отказа поддельному коммиту, выдачи/отсутствия APK.
- Компиляция четырёх backend-файлов, синтаксис встроенного JS, Bash и PowerShell.
- SHA-256 и размер опубликованного APK.
- Локальное открытие главной, каталога, заметок, загрузок, сервисов и настроек; проверка разметки и мобильной ширины. Предпросмотр не запускает Linux-команды.

## Границы проверки

Новая VM на настоящем Proxmox в рамках подготовки не создавалась. Доступность пакетов, инициализация cloud-init и обмен API с чистыми Servarr требуют отдельного интеграционного прогона на стенде. Код и тесты не являются подтверждением этого прогона.

Обновление действующего сервера, реальный сбой для проверки автоматического отката и удаление Jellyfin не выполнялись. Команды подготовлены для запуска владельцем. Показанные новые настройки проверяются в изолированном локальном предпросмотре; снимки библиотек 21.x относятся к существующему интерфейсу.

Личные ключи TMDB, закрытые трекеры, нестандартные сети Proxmox и аппаратное ускорение пользователь настраивает сам. Такие настройки нельзя безопасно заменить универсальными значениями.

Публичная версия перед выпуском обновлена до 22.1 параллельной задачей Android. APK 0.6.0 и сведения о пульте ТВ сохранены. Проверка обновлений после публикации получила настоящий commit GitHub и новости версии; отдельная установка на Proxmox всё ещё не выполнялась.
