# MediaHub v21.2 — Storage Wizard

## Что делает мастер

Storage Wizard предназначен для новой медиамашины, где MediaHub должен сам подготовить диски. Он работает только после явного выбора накопителей в Web UI.

### MediaPool

MediaPool — это набор отдельных ext4-дисков, объединённых mergerfs в одну точку `/mnt/media`.

Пример:

```text
/dev/sdb1 -> /mnt/mediahub-disks/disk-a1b2c3d4 \
                                                  +--> /mnt/media
/dev/sdc1 -> /mnt/mediahub-disks/disk-e5f6a7b8 /
```

Физические файлы остаются на конкретных ext4-дисках. mergerfs формирует единое дерево каталогов.

## Защита дисков

MediaHub запрещает выбор накопителя, если обнаружено хотя бы одно из условий:

- на нём находится `/`, `/boot` или `/boot/efi`;
- на диске есть смонтированный раздел;
- диск используется как swap;
- активен LVM, RAID или crypt-слой;
- диск уже является членом MediaPool;
- устройство read-only;
- `lsblk` видит диск, но его block-device не передан в `/dev`;
- нет доступа на запись к block-device.

Неразмонтированный диск со старой обычной файловой системой можно выбрать, но карточка отдельно предупреждает, что старая разметка будет удалена.

## Что происходит при создании пула

Для каждого выбранного диска выполняется:

```text
wipefs -a
parted: GPT
parted: один раздел на весь диск
mkfs.ext4
UUID
mount /mnt/mediahub-disks/disk-XXXXXXXX
```

После этого формируется управляемый блок `/etc/fstab`:

```text
# BEGIN MEDIAHUB STORAGE
...
# END MEDIAHUB STORAGE
```

Перед первой модификацией создаётся:

```text
/etc/fstab.mediahub-backup
```

## Добавление диска позже

1. Вставить новый диск.
2. Открыть **MediaHub → Установка**.
3. Нажать **Пересканировать диски**.
4. Выбрать новый диск со статусом **ДОСТУПЕН**.
5. Подтвердить удаление данных.
6. Нажать **Добавить диски в MediaPool**.

MediaHub временно остановит медиасервисы, размонтирует только объединённую точку MediaPool, добавит новую ветку в fstab, смонтирует пул снова и вернёт ранее работавшие сервисы.

## Существующая медиатека

Storage Wizard намеренно не накрывает новым mountpoint каталог, содержащий файлы. Если `/mnt/media` уже заполнена, используйте **Существующая папка** или новую точку для нового пула.

Автоматическая миграция существующей медиатеки в новый пул в v20 не выполняется: это отдельная операция, где важно не смешивать «создание пула» и «перемещение данных».

## Proxmox / LXC

В контейнере `lsblk` иногда показывает диски хоста, хотя block-device не передан контейнеру. В этом случае MediaHub помечает диск как недоступный.

Есть два нормальных варианта:

1. Создать/смонтировать хранилище на Proxmox и передать в LXC как mount point, затем выбрать **Существующая папка**.
2. Явно передать block-device в привилегированный контейнер с нужными правами и использовать Storage Wizard внутри контейнера.

Первый вариант обычно проще и безопаснее.

## RAID

MediaPool не является RAID. Отказ одного диска не делает остальные ext4-диски нечитаемыми, но файлы, которые физически лежали на отказавшем диске, будут потеряны без резервной копии.

RAID1/зеркало можно реализовать отдельным режимом мастера в следующей версии.
