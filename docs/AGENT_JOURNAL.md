# Журнал разработки публичного проекта

## 2026-10-04 — 22.0: дистрибутив GitHub

Публичный проект создан отдельной копией рабочей серверной версии 21.51. Существующая папка и действующий сервер не заменялись. Прочитаны прежний AGENTS.md, полный раздел устройства системы и журнал последних задач. Сохранены текущий плеер, карточки, загрузки и регрессионные тесты.

Добавлены отдельная Debian VM в Proxmox с cloud-init и диском медиатеки, автоматические подключения Servarr/qBittorrent, скачивание Android APK 0.6.0 и инструкции, новые настройки и GitHub-обновления. Резервная копия содержит старое приложение с окружением, env, базу и настройки запуска; при ошибке старта предусмотрен откат. Jellyfin исключён из recommended и управления службами; старые API оставлены для совместимости, фоновые ключи Jellyfin в новой версии отключены. Отдельный скрипт удаления пакета сохраняет его настройки.

Новый код установки стека остаётся в system_setup.py, HTTP-обработчики в app.py, интерфейс в templates/index.html/static/app.css. Скрипты scripts/ обслуживают распространение и системное развёртывание. Нет npm-сборки и новых CDN фронтенда.

Подробный план и пределы проверки — RELEASE_PLAN_RU.md. При дальнейшей работе не выдавать статические и mock-проверки за успешное создание VM или испытание отката на реальном сервере.

Перед публикацией сохранено параллельное обновление Android 0.6.0, android.json, VERSION.txt=22.1 и новости удалённого управления ТВ. Код remote API и его тесты уже присутствовали в снимке исходников; эти изменения не заменялись. Публичный пакет содержит новый APK, проверенный по SHA-256.
