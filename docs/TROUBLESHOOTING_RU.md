# Решение проблем MediaHUB 22.0

## Новая VM не завершила установку

Проверьте vmbr, DHCP (или адрес/маску, шлюз и DNS), интернет и место хранилища. VM автоматически не удаляется. На Proxmox: `qm guest exec ID_VM -- tail -n 80 /var/log/cloud-init-output.log` и `qm guest exec ID_VM -- tail -n 80 /var/log/mediahub-bootstrap.log`. Если гостевой агент ещё не готов, используйте консоль Proxmox для диагностики загрузки; пароль в cloud-образе не назначается.

## Не найдено хранилище snippets

Обычно используется local типа dir. Мастер добавляет snippets к его текущему content после CREATE. В нестандартной системе заранее подготовьте файловое хранилище с snippets. Хранилища images и snippets выполняют разные задачи; local-lvm подходит для дисков VM, но не для YAML-файла.

## Портал не открывается

Открывайте `http://IP_DEBIAN:8090`, а не IP Proxmox с портом 8006. Проверьте гостевой агент, сетевые правила Proxmox и `systemctl status mediahub`. Журнал: `journalctl -u mediahub -n 100 --no-pager`.

## Нет внешних подборок / релизов

Сохраните свой ключ TMDB для каталога; добавьте нужные индексеры в Prowlarr. Проверьте интернет и DNS сервера в «Источники → Диагностика сети». Недоступность одного внешнего сайта не означает, что локальные файлы потеряны. Для заблокированных каталогов можно настроить собственный прокси в подключениях.

## qBittorrent не отвечает

Проверьте `systemctl status qbittorrent-nox`. Внутренние подключения работают с localhost bypass; доступ к самому Web UI из сети сохраняет авторизацию qBittorrent. Временный пароль первого запуска доступен в карточке компонента или журнале: `journalctl -u qbittorrent-nox -n 100 --no-pager`.

## Сервисы установлены, но не связаны

Нажмите «Настройки → Связать установленные сервисы автоматически». Результат виден в `journalctl -u mediahub-connect`. Существующие записи с именем MediaHUB не создаются повторно. Для ручной команды см. INSTALL_RU.md.

## Тормозит видео

Выберите 480p, проверьте скорость сети и нагрузку CPU. HEVC может требовать программного перекодирования. Предпочтительно проводное соединение сервера/ТВ. Аппаратное ускорение этим установщиком не настраивается.

## Нет кнопки APK / APK не скачивается

Проверьте `/opt/mediahub/static/android.json` и наличие файла из filename. Выполните `python scripts/check.py` в исходном проекте: размер и SHA-256 должны совпадать. Поддерживаются Android 7.0+; APK не подходит для Tizen, webOS и iOS.

## Обновление не завершилось

Откройте «Ход обновления» или `journalctl -u mediahub-update`. Файл журнала: `/var/lib/mediahub/update.log`. Проверьте доступность GitHub, DNS и свободное место для staging и резервной копии. При ошибке старта прежняя версия восстанавливается; ручная процедура — UPDATES_RU.md.
