# История изменений MediaHUB

## 22.12 — 2026-10-04

- Новый интерфейс «Кино» (бета) — вторым вариантом рядом с классическим. Включается в «Настройки → Интерфейс» и действует только на этом устройстве: на телефоне можно включить новый, на компьютере оставить прежний. Переключение сразу, без перезагрузки.
- Первый этап «Кино»: глубокий тёмный фон со слоями вместо серого, голубой акцент, крупные скругления, стеклянная верхняя панель, компактное боковое меню с подписями при наведении, круглые кнопки и поля, мягкий подъём карточек при наведении, окна с плавным появлением и размытым фоном. Остальные разделы переводятся следующими версиями: карточки и главная, страница фильма и сериала, каталог и загрузки, мобильная версия, Android TV.
- Кнопка «Избранное» в окне карточки больше не заходит под крестик закрытия.
- Исправлено: установка с компьютера после автообновления с GitHub падала с ошибкой «pip: required file not found».

## 22.11 — 2026-10-04

- Android 0.8.2: коллекции видны и в приложении. В разделе «Фильмы» серия фильмов — одна карточка-стопка «Коллекция · 8» с годами и прогрессом; внутри — «Смотреть / Продолжить» со следующего фильма по порядку и все фильмы с номерами. У фильма из коллекции есть ссылка «Коллекция «…» · 2 из 8».
- Android 0.8.2: страница фильма больше не говорит о сериях: «Загружаем фильм…», без счётчика «1 видео», у фильма из нескольких файлов — «Части фильма».

## 22.10 — 2026-10-04

- Все окна портала в одном стиле: карточка проекта, окно «Смотреть», скачивание релиза и импорт используют одну поверхность, одинаковые скругления и один круглый крестик закрытия. Окно «Смотреть» больше не выделяется отдельной тёмно-синей гаммой; сезоны — чипы, как фильтры каталога.
- Кнопки действий приведены в порядок: в окне одна главная кнопка (например, «Смотреть»), остальные — спокойные вторичные; опасные действия красные. Кнопка «Избранное» в карточке снова круглая, а не вытянутая полоса.
- Подтверждения и ввод (удаление, переименование файла, смена сезона, снятие слежения, обновление, установка) открываются в окне портала вместо системных окон браузера; Esc и клик мимо окна отменяют действие.
- Постеры библиотеки, пропавшие после удаления Jellyfin, восстанавливаются надёжнее: сначала из сохранённых данных карточки, без обращения к интернету, а при недоступном TMDB синхронизация больше не зависает.

## 22.9 — 2026-10-04

- Коллекция фильмов, скачанная одной раздачей (например, все части «Гарри Поттера»), раскладывается по отдельным фильмам: у каждого своя папка «Название (Год)», своя карточка с постером, своё «Продолжить просмотр», а в блоке коллекции на странице фильма видно «В библиотеке 8 из 8». Субтитры и внешние дорожки уезжают вместе со своим фильмом, бонусы и сэмплы — в отдельную папку «… — доп. материалы».
- Сериалы, фильм из нескольких частей (CD1/CD2), Blu-ray-структура и раздачи без различимых названий по-прежнему остаются одной карточкой.
- Уже скачанную коллекцию можно разложить из карточки: «Здесь коллекция: N фильмов → Разложить по карточкам». В «Файлах» такие папки помечены, и перенос в «Фильмы» сразу раскладывает их по фильмам.
- Коллекции в библиотеке: фильмы серии показываются одной карточкой-стопкой «Коллекция · 8» с годами и прогрессом «просмотрено 3 из 8». В окне коллекции — фильмы по порядку, кнопка «Смотреть / Продолжить» со следующего непросмотренного, смена порядка, переименование и «Разобрать коллекцию» (фильмы остаются в библиотеке).
- Коллекцию можно собрать самому: «Моя библиотека → Собрать коллекцию», отметить фильмы в нужном порядке и дать название (подставляется общее начало названий). Отмеченные фильмы можно и добавить в существующую коллекцию. Раздача-коллекция после раскладки сразу собирается в коллекцию сама.
- Окно фильма больше не похоже на сериал: вместо блока «Серии и сезоны» с плиткой «Видео 1» — прогресс просмотра, «Продолжить», «С начала» и ссылка на коллекцию, если фильм в неё входит. У фильма из нескольких файлов блок называется «Части фильма».
- На телефоне в «Моей библиотеке» постеры карточек снова видны целиком, а не узкой полоской.
- После переноса папки из загрузок проводник больше не показывает «Папка не найдена» вместо сообщения об успехе.
- Android 0.8.1: каналы MediaHUB на главном экране Android TV, экран простоя с карточками тайтлов. Исправлено: после смены видео (следующая серия, запуск с телефона) пульт снова сразу управляет плеером, а «Пропустить заставку» нажимается кнопкой ОК, даже когда видна панель плеера.

# MediaHub v21.39 — Карточка со страницы сохраняется всегда

- Если сервер MediaHub не может открыть сайт (в браузере он открывается, а с сервера — нет), вместо пустой ошибки видно понятную причину и сразу раскрывается форма «Заполнить вручную».
- В форме можно перенести со страницы название, год, ссылку на постер, жанры, число серий и описание. Карточка затем показывает только эти данные — так же, как при загрузке со страницы.
- Сервер теперь пробует открыть страницу ещё раз только по IPv4 и через внешний прокси, если он настроен.
- Если данные со страницы подставлены, пока карточка ещё дозагружалась, поздний ответ каталога их больше не затирает. При повторном открытии карточка сразу показывает сохранённые данные.

# MediaHub v21.37 — Разбор страниц и выбор раздачи

- По ссылке MediaHub ищет торренты и magnet-ссылки в ссылках страницы, кнопках и строках встроенных скриптов.
- Если вариантов несколько, появляется список с названиями и подписями. Скачивается выбранный вариант; случайный первый торрент больше не запускается.
- Данные проекта собираются из JSON-LD, OpenGraph и полей «Название», «Год выхода», «О фильме», «Жанр». Улучшен подбор постеров и поддержка старых кодировок сайтов.
- Номер сезона со страницы предлагается автоматически. Категория и объединение с существующим проектом остаются на выбор пользователя.
- Для скачивания передаётся адрес страницы-источника. Если сайт требует входа или CAPTCHA, интерфейс объясняет причину.
- Страницы без открытых торрентов сохраняют свои данные; к ним можно приложить собственный .torrent.

# MediaHub v21.37 — Файлы проекта в карточке и мгновенная библиотека

- Блоки «Переименовать», «Объединить», «Файлы проекта» и «Удалить» появляются в карточке сразу при открытии, а не после того, как MediaHub дозагрузит описание.
- Раскрытые блоки и введённый текст больше не сбрасываются, когда карточка дорисовывается полными данными.
- В карточке появился список файлов проекта по папкам и сезонам: формат, размер и то, играет ли файл.
- Любой файл можно переименовать (одноимённые субтитры переименуются вместе с ним), перенести серию в другой сезон или удалить с диска.
- «Моя библиотека» показывает изменения сразу: новые загрузки, перенесённые, объединённые и удалённые папки, новые серии в сезоне. Раньше они появлялись только через 10 минут.

# MediaHub v21.36 — Автоматический ввод пароля установщиком

- Установочный BAT запоминает SSH-пароль и автоматически использует его при копировании, установке и проверке сервера.
- Пароль хранится зашифрованно в Windows для текущего пользователя, отдельно от проекта и установочного архива.
- Сменить пароль можно командой `DEPLOY_MEDIAHUB.bat IP_СЕРВЕРА root reset`.
- Ошибка заключительной проверки теперь останавливает установщик вместо сообщения об успехе.

# MediaHub v21.35 — Объединение проектов и карточки только со страницы

# MediaHub v21.5 — Распознавание сезонов
